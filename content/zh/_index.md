# OpenClaw 🦞

**"EXFOLIATE! EXFOLIATE!" — 一只太空龙虾，也许**

OpenClaw 是一个开源的 AI 代理平台，让您可以通过 WhatsApp、Telegram、Discord、iMessage 等消息渠道与 AI 代理交互。发送一条消息，即可从口袋中获得智能响应。插件系统支持扩展更多平台如 Mattermost。

## 什么是 OpenClaw？

OpenClaw 是一个功能强大的 AI 代理运行时环境，专为构建和部署智能代理而设计。它将大型语言模型的能力与工具调用、会话管理、多代理协作等高级功能相结合，创建了一个完整的代理生态系统。

### 核心特性

- **🤖 智能代理**：基于大型语言模型的智能代理，能够理解自然语言并执行复杂任务
- **🛠️ 工具调用**：支持调用浏览器、执行命令、发送消息等多种工具
- **💬 多频道支持**：无缝集成 WhatsApp、Telegram、Discord、iMessage 等主流消息平台
- **🧠 会话记忆**：持久的会话管理，保持对话上下文和长期记忆
- **👥 多代理协作**：多个代理协同工作，处理复杂的工作流程
- **🔧 可扩展架构**：模块化设计，支持自定义工具、插件和集成
- **🛡️ 安全可靠**：内置权限控制、审批流程和安全防护机制

## 工作原理

OpenClaw 采用分层的架构设计：

1. **网关层**：核心服务，管理所有连接和通信
2. **代理层**：智能代理运行时，处理用户请求和工具调用
3. **工具层**：丰富的工具库，扩展代理的能力边界
4. **频道层**：消息平台集成，实现跨平台交互
5. **节点层**：设备客户端，支持 macOS、iOS、Android 等平台

### 代理执行流程

```
用户消息 → 频道接收 → 网关路由 → 代理处理 → 工具调用 → 响应生成 → 返回用户
```

## 快速开始

### 1. 安装 OpenClaw

在几分钟内安装 OpenClaw 并启动网关服务：

```bash
# 使用安装脚本
curl -fsSL https://openclaw.dev/install.sh | sh
```

### 2. 运行配置向导

启动交互式配置向导，轻松完成初始设置：

```bash
openclaw setup
```

### 3. 连接消息频道

按照指南连接您的 WhatsApp、Telegram 或其他消息账户。

### 4. 开始对话

向已连接的频道发送消息，OpenClaw 代理将立即响应。

## 关键能力

### 🧩 工具使用

OpenClaw 代理可以调用丰富的工具集：

- **浏览器控制**：网页浏览、表单填写、内容提取
- **命令执行**：在受控环境中运行 shell 命令
- **文件操作**：读写文件、编辑内容、管理文档
- **消息发送**：跨平台消息发送和管理
- **网络请求**：HTTP 请求、API 调用、数据获取

### 🔄 会话管理

- **持久化会话**：保存对话历史和执行状态
- **上下文感知**：保持长期对话连贯性
- **会话修剪**：智能清理过期会话以优化性能
- **记忆压缩**：高效存储会话记忆

### 👥 多代理系统

- **代理协作**：多个代理分工合作处理复杂任务
- **路由策略**：智能路由请求到最合适的代理
- **层级架构**：主代理和子代理的层级管理
- **专业分工**：不同代理专注于特定领域

### 🌐 跨平台支持

- **桌面端**：macOS、Windows、Linux
- **移动端**：iOS、Android
- **消息平台**：WhatsApp、Telegram、Discord、iMessage、Signal、Slack
- **部署方式**：本地部署、云部署、容器化部署

## 仪表板和控制界面

OpenClaw 提供直观的 Web 控制界面：

- **实时监控**：查看代理状态、会话统计和系统性能
- **配置管理**：图形化配置工具、频道和代理设置
- **日志查看**：详细的执行日志和调试信息
- **权限控制**：用户管理和访问控制

## 配置（可选）

根据您的需求进行高级配置：

- **模型设置**：配置使用的 LLM 模型和参数
- **工具管理**：启用/禁用特定工具，设置权限
- **频道集成**：配置多个消息频道和账户
- **安全策略**：设置审批流程、访问控制和审计日志
